# 👑 SH BAKHUR — Royal & Luxury Design System

> **Brand:** متجر SH للبخور والعطور الفاخرة (`shbakhur.com`)  
> **Aesthetic Philosophy:** Royal Black & Imperial Gold Opulence (الفخامة الملكية الشرقية)  
> **Status:** APPROVED & LOCKED

## 1. Color Palette Tokens

| Token | Hex Value | Semantic Usage |
|:---|:---|:---|
| `primary-dark` | `#0a0a0a` | **Global Page Backdrop** (Deep Luxury Black) |
| `surface-card` | `#141414` | Elevated Product Card & Modal Surface |
| `surface-border` | `#262626` | Card dividers & delicate gold-tint borders |
| `accent-gold` | `#d4af37` | **Primary Brand Metallic Gold** (Emblems, Stars, Active Tabs) |

| `accent-gold-dark` | `#997a15` | Deep gold borders & muted labels |
| `text-primary` | `#ffffff` | Main titles & critical headers |
| `text-secondary` | `#a3a3a3` | Product descriptions, specs, and weights |
| `text-gold` | `#d4af37` | VIP badges, currency units (ر.س) |

## 2. Typography & Iconography
- **Primary Font:** Cairo / Readex Pro for clean, modern Arabic flow.
- **Direction:** RTL native (`dir="rtl"`).
- **Icons:** Lucide React (Clean, linear icons strictly replacing all emojis).
- **Badges:** Royal gold pill badges (`الأكثر مبيعاً`, `عود طبيعي فاخر`, `تعتيق خاص`).
